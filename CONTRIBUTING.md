# Contributing to OpenLegalCore Community

Thank you for helping improve OpenLegalCore.

## Start a useful discussion

1. Search existing discussions before creating a new one.
2. Choose the category that best matches your topic.
3. State the problem or question clearly.
4. Add verified context, examples, and links where they are safe to publish.
5. Explain the outcome you would like to see.
6. Keep one primary topic per discussion.

For technical proposals, include the problem, constraints, proposed approach, serious alternatives, and relevant risks. Claims about quality, performance, cost, or legal effect should include a reproducible method or an authoritative source.

## Use the right place

- Use organization Discussions for project-wide questions, ideas, proposals, and governance topics.
- Use the affected repository's issue tracker for reproducible bugs and concrete tasks.
- Use a pull request in the affected repository for reviewed changes.
- Use the private reporting path described in [SECURITY.md](SECURITY.md) for vulnerabilities or sensitive incidents.
- Use Slack only for invited collaboration that is not suitable for a public forum.

## Never post publicly

Do not publish:

- private or client legal documents;
- personal or confidential data;
- credentials, tokens, private URLs, or deployment details;
- undisclosed vulnerabilities or active incident details;
- contractual or partner-confidential information;
- private source code or sensitive architecture.

Use synthetic or properly cleared examples. If you are unsure whether information is safe to publish, do not post it.

## Expectations

Be precise, constructive, and respectful. Critique ideas and evidence, not people. Maintainers may edit categories, close duplicates, lock harmful threads, or move actionable work to an issue. Participation is governed by the [Code of Conduct](CODE_OF_CONDUCT.md).

OpenLegalCore is founder-led. A discussion creates an opportunity for review; it does not by itself commit the project to a decision, implementation, support obligation, or release date.
