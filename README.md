# OpenLegalCore Community

This repository is the public community home for [OpenLegalCore](https://openlegalcore.org).

Use [OpenLegalCore Discussions](https://github.com/orgs/OpenLegalCore/discussions) for public questions, ideas, proposals, and project-wide conversations.

## Where to participate

- **Questions and help:** ask how a public OpenLegalCore component works.
- **Ideas and proposals:** suggest a feature, integration, research direction, or RFC.
- **Governance and method:** discuss project-wide rules, evidence standards, release methods, and public decisions.
- **General:** share relevant resources and community updates.
- **Bugs and actionable tasks:** open an issue in the affected repository, not here.

## Public and private boundaries

OpenLegalCore follows a **public foundation + private incubation** model. Public discussion is welcome, while security, privacy, active incidents, contractual information, production data, private legal documents, and sensitive architecture are handled privately.

Do not publish confidential information, personal data, credentials, client material, or security vulnerabilities in this repository or its Discussions. See [SECURITY.md](SECURITY.md) for the safe reporting route.

Slack is reserved for invited collaborators and partners. Decisions that affect the public project should be summarized in a durable public record when it is safe to do so.

## Project governance

OpenLegalCore is founder-led. Community input is considered on its merits, but public discussion is not a vote. Significant decisions should record the problem, verified context, chosen approach, alternatives, consequences, status, owner, and date. See [GOVERNANCE.md](GOVERNANCE.md).

## Before posting

Please read [CONTRIBUTING.md](CONTRIBUTING.md) and our [Code of Conduct](CODE_OF_CONDUCT.md). OpenLegalCore does not provide legal advice through GitHub Discussions.
