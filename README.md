# OpenLegalCore Community

This repository is the public community home for
[OpenLegalCore](https://openlegalcore.org/). The
[component register](https://openlegalcore.org/components/) is the current public
record of the project's nine-component system, including which components are
public, private or planned.

Use [OpenLegalCore Discussions](https://github.com/orgs/OpenLegalCore/discussions)
for public questions, ideas, proposals and project-wide conversations.

## Where to participate

- **Questions and help:** ask how a public OpenLegalCore component works.
- **Ideas and proposals:** suggest a feature, integration, research direction or
  RFC.
- **Legal, methodological and source review:** identify a bounded issue, cite
  the relevant authority or source and explain the proposed correction.
- **Governance and method:** discuss project-wide rules, evidence standards,
  release methods and public decisions.
- **Bugs and actionable tasks:** open an issue in the affected repository, not
  here.
- **Partnerships and commercial work:** use the contact path published on the
  [project website](https://openlegalcore.org/#contribute).

## Public and private boundaries

OpenLegalCore follows a **public foundation + private incubation** model. Public
discussion is welcome, while security, privacy, active incidents, contractual
information, production data, private legal documents and sensitive
architecture are handled privately.

Do not publish confidential information, personal data, credentials, client
material or security vulnerabilities in this repository or its Discussions.
See [SECURITY.md](SECURITY.md) for the monitored private reporting route.

Slack is reserved for invited collaborators and partners. Decisions that affect
the public project should be summarized in a durable public record when it is
safe to do so.

## Project governance

OpenLegalCore is founder-led and publicly accountable. Rajko Majcen, Founder /
Product Lead, currently holds the named project-wide decision rights described
in [GOVERNANCE.md](GOVERNANCE.md). Community input is considered on its merits,
but public discussion is not a vote.

## Before posting

Please read [CONTRIBUTING.md](CONTRIBUTING.md) and our
[Code of Conduct](CODE_OF_CONDUCT.md). OpenLegalCore does not provide legal
advice through GitHub Discussions.
